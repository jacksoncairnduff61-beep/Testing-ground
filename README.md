# Testing Ground

A thinking repo: test, brainstorm and explore here, condense into a map, and move
ideas that become real into their own repos.

- **[MAP.md](MAP.md)** — index of all ideas and their status. Start here.
- **[INBOX.md](INBOX.md)** — quick unsorted captures.
- **`ideas/`** — one folder per idea (`notes.md` + any prototypes).
- **`templates/PROPOSAL.md`** — fill in before graduating an idea.
- **`graduated/`** — pointers to ideas that became their own repos.
- **[CLAUDE.md](CLAUDE.md)** — the rules Claude follows in every session here.

**Lifecycle:** `raw` → `exploring` → `promising` → `graduated` (or `parked` / `dropped`; nothing is deleted)

**Capturing away from Claude:** open a GitHub Issue with the "Idea capture" template.
It gets filed into the repo during the next session.
